# DreamStream - 助眠白噪音应用

## 1 How to Run

### 本地开发
```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

### Docker 运行
```bash
# 构建并启动
docker-compose up -d --build

# 访问
http://localhost:8082
```

## 2 Services

该项目包含以下服务：

- **Frontend**: 基于 Nginx 托管的 Vue 3 单页应用 (端口 8082)

本项目为纯前端应用，无需登录即可使用所有功能。

## 4 题目内容

你好，作为一名专业网页程序开发师，现需设计并开发一款针对失眠患者的网页版助眠软件。该软件应具备后台运行功能，确保用户在浏览其他网页或最小化浏览器窗口时仍能继续提供助眠服务。开发过程中需遵循以下具体要求：1. 核心功能开发：- 实现多种助眠音频播放功能（如白噪音、自然环境音、轻音乐等）- 提供音频混合功能，允许用户自定义组合不同音频元素- 设计睡眠计时器功能，支持定时关闭或渐弱音量- 开发用户个性化设置面板，可保存用户偏好设置2. 后台运行技术要求：- 采用Web Audio API结合Service Workers实现浏览器后台音频播放功能- 确保在主流浏览器（Chrome、Firefox、Safari最新版本）中稳定运行- 实现浏览器标签页切换或最小化时的无缝播放体验3. 用户界面设计：- 采用舒缓的色彩方案和简洁直观的操作界面- 实现响应式设计，确保在桌面端和移动设备上均有良好表现- 添加视觉反馈机制，如音量调节动画、播放状态指示等4. 性能与兼容性要求：- 优化音频加载速度，实现预加载和缓存机制- 确保低CPU和内存占用，避免影响用户设备性能- 实现渐进式Web应用(PWA)功能，支持离线访问核心功能5. 安全与可访问性：- 遵循Web Content Accessibility Guidelines (WCAG) 2.1标准- 确保用户数据本地存储安全，不收集敏感个人信息- 实现适当的错误处理和用户提示机制请根据以上需求进行详细的技术方案设计、界面原型开发、功能实现与测试验证，最终交付一个功能完整、性能稳定、用户体验优良的网页版助眠软件。

本应用是一款针对失眠患者的网页版助眠软件，具备多轨音频混合、后台播放、PWA 离线支持、定时关闭等功能。

## 项目介绍

DreamStream 是一款专注于睡眠辅助的 Web 应用。

### 核心功能
- 🎵 **多轨混音**：支持白噪音、雨声、风声等多种音频同时播放并独立调节音量。
- ⏳ **智能定时**：支持 15/30/60 分钟自动关闭，音量渐弱。
- 📱 **PWA 支持**：可安装到桌面/手机，支持离线运行。
- 🎨 **沉浸体验**：深色护眼模式，舒缓动画。

### 技术栈
- Vue 3 + TypeScript + Vite
- Element Plus
- Pinia (State Management)
- Web Audio API (Audio Engine)
- Service Workers (PWA)
